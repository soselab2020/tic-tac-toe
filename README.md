# Tic-Tac-Toe

A simple browser-based Tic-Tac-Toe game written in HTML and JavaScript.

## How to Play
1. Open `tic-tac-toe.html` in any web browser.
2. Two players take turns clicking on the grid to place X and O.
3. The first player to get three in a row (horizontally, vertically, or diagonally) wins.
4. If all nine squares are filled with no winner, the game is a draw.
